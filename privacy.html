yt-trends プライバシーポリシー

最終更新: 2026年10月21日

要約

yt-trends の利用者は開発者本人 1 名だけです。Google アカウントから取得した情報は本人の Mac の中で処理し、本人以外の誰にも提供しません。アカウント登録・広告・アクセス解析はありません。

取得する情報と、その目的

  • YouTube Analytics（読み取り専用 / yt-analytics.readonly）
    本人が運営するチャンネルの、動画ごとの再生回数・視聴時間・視聴率・流入元・登録者の増減などを取得し、次に作る動画の題材や作り方を決めるために集計します。
  • YouTube（読み取り専用 / youtube.readonly）
    同意したチャンネルがどれかを確かめるために、チャンネルの ID と名前を取得します。動画のアップロード・変更・削除、コメントの投稿などは一切行いません。

保存する場所

取得した内容は、本人の Mac の中にのみ保存されます。開発者が運営するサーバーは存在せず、外部のデータベースに保管することはありません。

外部に送信される場合

集計した数値の分析に AI モデルを使用することがあります。この処理のため、集計した数値は Anthropic の Claude に送信されることがあります。これ以外に、Google アカウントから取得した情報を第三者へ送信・提供・販売・譲渡することはありません。

Google ユーザーデータの取り扱い

yt-trends による Google API から取得した情報の利用および他アプリへの移転は、Google API サービスのユーザーデータに関するポリシー（限定利用（Limited Use）の要件を含む）に従います。取得した情報を広告目的で利用することはありません。YouTube のデータの扱いは YouTube 利用規約 と Google プライバシー ポリシー にも従います。

アクセスの取り消しとデータの削除

Google アカウントのサードパーティ アプリとサービスから、本アプリのアクセス権をいつでも取り消せます。端末上に保存された資格情報および取得済みのデータは、本人が該当ファイルを削除することで消去されます。

本ポリシーの変更

変更した場合は、本ページの最終更新日を改めます。
